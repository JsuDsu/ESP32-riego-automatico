# Sistema de riego automático con ESP32

Proyecto para controlar y monitorear un sistema de riego automático con ESP32.

## Archivos
- `ESP32-riego-automatico.ino`
- `Secrets_example.h`

## Configuración
1. Copia `Secrets_example.h`
2. Renómbralo a `Secrets.h`
3. Completa tus credenciales

## Importante
`Secrets.h` no se sube por seguridad.
